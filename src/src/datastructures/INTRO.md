
# What is Data Structures?
Data structures are different forms and ways to organize and store data so that it can be processed and used efficiently.
Raw information becomes data after it is processed. This repository covers the foundational structures used to organize that data, categorized by how they arrange information.
## Classification of Data Structures
### 1. Linear Data Structures
Data elements are stored in a sequential or nearly sequential order, where each element is connected to its previous and next adjacent elements.
• Arrays: Collections of elements stored at contiguous memory locations.
• LinkedList: Linear collections of data elements where each element points to the next.
• Stack: Sequential structures following the Last-In, First-Out (LIFO) principle.
• Queue: Sequential structures following the First-In, First-Out (FIFO) principle.
### 2. Non-Linear Data Structures
Instead of following a linear sequence, data is stored in a hierarchical or interconnected way, where elements can connect to multiple other elements.
• Tree: A hierarchical structure representing data in a parent-child relationship.
• Graph: A network of nodes (vertices) connected by links (edges).
### 3. Hash-Based Data Structures
Data is stored in key-value pairs using a mechanism called hashing to significantly optimize data retrieval and processing speeds.
• HashMap: A structure that maps unique keys to specific values.
• HashSet: A collection of unique elements optimized for fast membership checking.
